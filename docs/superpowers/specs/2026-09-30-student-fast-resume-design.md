# Student Fast Resume Design

## Goal

학생이 연구기간 동안 로그인과 푸시 알림 등록을 안정적으로 유지하면서, 앱 재실행 시 로그인 화면이 깜빡이지 않고 기록 데이터가 빠르게 표시되게 한다.

## Approved behavior

- 첫 화면에서는 로그인과 메인 앱을 모두 숨기고 중립적인 로딩 화면을 표시한다.
- 유효한 학생 세션이면 로그인 화면을 거치지 않고 메인 앱으로 전환한다.
- 세션이 없거나 유효하지 않을 때만 로그인 화면을 표시한다.
- 학생 세션은 90일이며, 유효한 세션을 확인할 때 만료일을 다시 90일 뒤로 연장한다.
- 명시적 로그아웃만 현재 기기의 푸시 구독을 해제한다.
- 상단 로그아웃 버튼은 제거하고 설정 화면의 `학생 변경·로그아웃`으로 옮긴다.
- 로그아웃은 알림 중지 안내를 포함한 2단계 확인을 거친다.
- 일반 재실행에서는 기존 3초 지연을 제거한다. 실제 카메라 분석이 진행 중일 때만 데이터 호출을 미룬다.
- 체중·통계·카페인 기록·수면 기록·수면 설정을 하나의 학생 초기 데이터 요청으로 묶는다.
- 초기 데이터 요청 실패 시 기존 개별 요청으로 안전하게 대체한다.
- 건강 데이터는 브라우저 저장소에 새로 캐시하지 않는다.

## Security

- 학생 식별자는 서명된 HttpOnly 세션에서만 Apps Script로 전달한다.
- 통합 초기 데이터 요청도 학생 역할 허용목록과 서버 측 신원 덮어쓰기를 통과한다.
- 세션 및 초기 데이터 응답은 `no-store`를 유지한다.

## Verification

- 세션 확인 전 로그인 화면이 노출되지 않는다.
- 인증 성공 시 로딩 화면에서 메인 앱으로 바로 전환한다.
- 인증 실패 시 로그인 화면을 표시한다.
- 통합 초기 데이터가 각 화면 상태에 반영되고 실패 시 개별 호출이 실행된다.
- 세션 확인이 새 90일 쿠키를 발급한다.
- 상단 로그아웃이 사라지고 설정의 경고된 2단계 로그아웃만 남는다.
- 기존 푸시 알림과 Apps Script 보안 테스트가 모두 통과한다.
