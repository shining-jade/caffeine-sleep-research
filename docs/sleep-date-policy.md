## 1. 용어 정의

| 용어 | 정의 | 비고 |
|---|---|---|
| 기상일 | 학생이 보고한 기상 시각의 날짜 (Asia/Seoul) | 학생 화면 "기상 날짜·시간"에서 입력 |
| **수면 대상일** | **주수면의 기상일 − 1일** | 분석·피드백의 기준 날짜. 헬퍼에서는 '수면 분석일', 시트 열은 `주수면분석대상일` |
| 잠자리에 있던 시간 | 보고된 취침 시각 ~ 기상 시각 사이의 시간 | 자가보고 시각 간 시간이며 **실제 총수면시간이 아님** |
| 다음 날 아침 컨디션 | 기상 후 컨디션(1~5점) | 수면 대상일 D의 잠의 결과이며, 실제 기록은 D+1일 아침 |

학생 화면은 일상 표현을 그대로 씁니다("☀️ 오늘 아침 — 기상", "🌙 어젯밤 — 잠들기 전", "😴 어젯밤 — 수면 중"). 학생이 아침에 '어젯밤 잠'을 기록하면, 시스템이 그 잠을 어젯밤 날짜(= 기상일 − 1)에 붙입니다.

## 2. 수면 대상일 규칙

### 2.1 기본 규칙

**주수면의 수면 대상일 = 실제 기상일(Asia/Seoul)의 전날.** 취침 날짜가 아니라 기상일로 계산합니다.

| 사례 | 취침 | 기상 | 수면 대상일 |
|---|---|---|---|
| 보통 | 11/4 23:27 | 11/5 06:55 | **11/4** |
| 자정 넘겨 취침 | 11/2 01:21 | 11/2 06:55 | **11/1** |
| 일찍 취침 | 11/2 21:27 | 11/3 06:58 | **11/2** |
| 주말 늦잠 | 10/31 23:21 | 11/1 09:20 | **10/31** |

### 2.2 예외와 보류

- **낮잠·미분류·유형 미수집** 기록에는 수면 대상일을 붙이지 않고 별도로 보존합니다. 유형 미수집 기록은 '검토 대상'으로 표시합니다.
- **같은 수면 대상일에 주수면이 2건 이상**이면 분석하지 않고 보류합니다(`multiple_main`).
- **기록 ID 충돌**(소유자 불일치, 같은 수정 버전에 서로 다른 내용)이 있으면 보류합니다(`identity_conflict`). 나중 수정본이 있어도 충돌을 해소한 것으로 보지 않습니다.
- 수정된 기록은 같은 ID의 가장 높은 수정 버전만 사용하고, 삭제 상태인 기록은 제외합니다.
- 미기록일은 0이나 '미섭취·미수면'으로 추정하지 않고 계산에서 제외합니다.

### 2.3 시간대

모든 날짜 계산은 Asia/Seoul 기준입니다. 시간대 표기가 없는 날짜·시각 문자열은 한국 시각으로 해석합니다.

## 3. 카페인과 수면의 연결

| 방식 | 규칙 | 사용처 |
|---|---|---|
| 날짜 단위 | 카페인 섭취일 D ↔ 수면 대상일 D | 학생 표 '해당 날짜 수면기록 상태', 일별 기준 체크, 의사결정트리 학습용 행 |
| 시간창 단위 | 보고된 취침 시각 이전 24시간 [취침−24h, 취침) 의 섭취량 | 전처리 헬퍼 산점도 (`caffeine_window_for_sleep`) |

- 섭취일은 섭취 시각의 날짜(Asia/Seoul)입니다.
- 시간창에 함량을 알 수 없는 기록이 있으면 합계는 '알 수 없음'으로 두고 0으로 바꾸지 않습니다.
- 신체활동처럼 아침 수면 기록에서 '어제'를 묻는 항목은 수면 대상일 D의 활동으로 봅니다.

**한 줄 요약:** D일 낮의 생활(카페인·활동) → D일 밤의 잠(수면 대상일 D) → D+1일 아침 컨디션.

## 4. 화면·피드백 표기 규칙 (2026-11-05 확정)

2026-11-05 학생 피드백 보고서 화면을 검토하면서 아래 문제를 발견했고, 연구자가 아래 규칙으로 고치기로 확정했습니다.

| 번호 | 발견한 문제 | 규칙 |
|---|---|---|
| A | 한 보고서 안에서 날짜 축이 두 개임. 건강 기준 체크 표·취침 시각 점·주수면 기록표는 수면 대상일, 컨디션 칩·컨디션 막대는 기상일 기준 → 그래프에서 한 번의 잠이 한 칸씩 어긋나 보임 | **보고서 전체를 수면 대상일 축 하나로 통일.** 컨디션은 대상일 칸에 놓고 "다음 날 아침 컨디션"으로 표기 |
| B | '평일'을 수면 대상일 월~금으로 계산 → 금요일 밤(다음 날 토요일)이 평일에 들어가고 일요일 밤(다음 날 등교)이 빠짐 | **등교일 전날 밤 = 수면 대상일 일~목**(= 기상일 월~금)으로 정의. 문구는 "등교일 전날 밤 평균". 공휴일·재량휴업일은 요일로 구분할 수 없음을 한계로 기록 |
| C | 아직 오지 않은 밤(기상일이 오늘 이후인 수면 대상일)이 기간에 포함되어 '–'로 표시되고 기록 일수 분모에 들어갈 수 있음 | 기상일이 오늘 이후인 수면 대상일은 수면 분모에서 제외하고 "아직"으로 표시 |
| D | "10.30에는 … 그날 아침 컨디션은 2점" → 10.30 아침으로 읽힘 | "10.30 밤에는 … 다음 날(10.31) 아침 컨디션은 2점이었어요." |

## 6. 논문 연구방법과의 연결

### 6.1 연구방법 정의 문장 (초안)

> 주수면 기록은 학생이 보고한 기상 날짜의 전날을 수면 대상일로 정의하였다. 자정 이후에 잠자리에 든 경우에도 기상 날짜를 기준으로 하여 전날 밤의 수면으로 분류하였다. 카페인 섭취는 섭취일과 같은 날짜의 수면 대상일에 연결하였으며, 산점도 분석에서는 보고된 취침 시각 이전 24시간의 섭취량을 사용하였다. 취침 시각과 기상 시각 사이의 시간은 자가보고에 근거한 '잠자리에 있던 시간'으로, 실제 총수면시간과 구분하였다.

### 6.2 선행 연구·기기와의 비교

| 기준 | 수면에 붙이는 날짜 | 카페인 짝 |
|---|---|---|
| Consensus Sleep Diary (Carney et al., 2012) | 작성하는 날 아침 날짜(기상일) | 전날 낮 활동은 전날 밤에 기록 |
| Fitbit, Garmin | 기상일 | — |
| Oura | 오후 6시~오후 6시 '수면일' | — |
| 본 연구 | 수면 대상일(기상일 − 1) | 같은 날짜 |

두 방식이 만드는 쌍은 "D일 낮 → D일 밤 수면"으로 같고, 라벨만 다릅니다. 본 연구는 원인(낮의 카페인)과 결과(그날 밤 잠)가 같은 행에 놓이도록 수면 대상일 라벨을 사용합니다.

- Carney, C. E., Buysse, D. J., Ancoli-Israel, S., Edinger, J. D., Krystal, A. D., Lichstein, K. L., & Morin, C. M. (2012). The consensus sleep diary: Standardizing prospective sleep self-monitoring. *Sleep, 35*(2), 287–302. https://doi.org/10.5665/sleep.1642 (초록과 공개 양식만 확인함, 본문 대조 필요)
